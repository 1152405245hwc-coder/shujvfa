# 示例数据说明（数据 / 知识库来源声明）

## 数据性质

本目录下所有材料均为**项目组自行构造的虚构案卷**，用于模拟诈骗类案件的起诉书、被害人陈述、证人证言及银行流水。所有人物、身份证号、银行账号、公司名称、案号均为虚构，不指向任何真实个人或机构。

## 用途

仅用于：

1. 界面演示（Landing 页「打开演示案件」）；
2. 功能体验（上传流程的参考样例）；
3. 回归测试与评测基线（Gold Case / Holdout Case）。

## 与智能体的关系

**本目录不属于智能体运行的必需组成部分。** 删除整个 `sample_data/` 目录后，系统仍可通过界面上传评审方自备的案卷材料，完成从材料导入、结构化解析到资金证据审查的完整流程；仅演示案件入口与回归测试不可用。

## 知识库

**无。** 本项目当前版本不使用任何外部领域知识库 / RAG 知识库 / 向量检索库。所有核验规则、金额计算、状态机与法律边界提示均为代码内置的确定性逻辑，可离线运行。

## 目录构成

| 目录 | 内容 |
| --- | --- |
| `demo_case_001/` | 最小演示案件（起诉书 + 被害人陈述 + 流水 CSV） |
| `case_packages/GOLD_CASE_001/` | 金标准回归案件一（单被害人） |
| `case_packages/GOLD_CASE_002/` | 金标准回归案件二（多被害人、三笔指控，含 hidden 比对材料） |
| `gold_cases/` | 金标准断言集（G01–G05 + manifest） |
| `holdout_cases/` | 留出验证集（H01–H05 + manifest） |
