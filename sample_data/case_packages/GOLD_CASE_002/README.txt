# GOLD_CASE_002 Test Package

本案例包内的可见材料已按国内法律文书规范统一处理：
1. 目录名沿用 visible/hidden 结构，文件名统一为中文法律文书命名（如 01_起诉书.docx）；
2. 文书（起诉书、陈述、证言、供述、聊天记录、项目资料）均已按标准法律文书格式排版（A4、公文页边距、二号黑体标题、三号仿宋正文、28磅行距、首行缩进两字符）；
3. 银行流水工作簿按证据材料样式排版（表头、边框、列宽、冻结），工作表名与全部数据保持不变；
4. 文档正文内容未作改动。

重要：
1. 文档正文仍为中文，不影响测试；
2. hidden/ 为隐藏真值，不应提供给模型；
3. FILE_NAME_MAP.txt 提供当前文件名与材料名称对照及原 ASCII 文件名存档。

建议系统测试时只加载 visible/。
