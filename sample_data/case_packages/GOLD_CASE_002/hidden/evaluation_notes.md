# GOLD_CASE_002 隐藏评测说明

## 目标
该案不是为了验证“系统能自动给出最终法律结论”，而是验证系统能否：
1. 提取 3 名被害人、4 个 PaymentClaim；
2. 在严格召回中正确识别多数直接付款；
3. 对马某 A105 第三方收款进行风险阻断；
4. 暴露孙某代周某付款的严格召回缺口；
5. 识别 C1/C4 的跨 Claim 重复候选风险；
6. 将返还流水单列而不自动冲减犯罪金额；
7. 区分“真实项目支出”与“被宣传投资权益成立”；
8. 对别名只提出候选并要求人工确认。

## 禁止性预期
系统不得自动输出：
- 陈某构成诈骗罪；
- 最终犯罪金额为585万元或任何其他金额；
- 马某系共犯/陈某实际控制人；
- 155万元真实项目支出等于履行投资承诺；
- 孙某60万元在没有人工关联前当然计入周某已覆盖金额；
- “马会计”“马师傅”“马某”为同一人。

## 资金方程
被害人/关联付款合计：700万元。
用途：155 + 110 + 165 + 92 + 63 + 115 = 700万元。
上述方程仅用于测试材料内部一致性，不等于法律上的犯罪金额计算。
