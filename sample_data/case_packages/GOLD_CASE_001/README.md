# GOLD_CASE_001 案例包

版本：0.2.0  
性质：合成材料，用于项目交叉核验与隐藏评测

## 目录约定

- `visible/`：可提供给被测试模型的材料。银行流水保留原始多账户工作簿，文书保留原始 DOCX。
- `hidden/`：仅评测方使用，含隐藏真值、题库和评测说明；禁止复制到模型输入目录。
- `derived/victim_payments.csv`：从可见银行流水抽取的 18 笔朱某付款索引，字段符合项目交易 CSV 规范。它是便于程序化测试的派生文件，不替代原始流水。
- `case_manifest.json`：文件清单与金额控制总表。

## 关键控制数

- 朱某累计付款：7,368,000 元（18 笔）
- 直接进入何某 A002/A003：6,118,000 元
- 进入林某 A005：1,250,000 元
- 何某及关联账户返还朱某：1,326,000 元
- 进入证券账户：1,268,000 元

运行项目现有的单 CSV 流程时，优先使用 `derived/victim_payments.csv`；需要测试多账户归并、双边流水去重或资金用途推理时，必须使用 `visible/bank/02_银行流水账单.xlsx` 并按原始交易时间、流水号和账户 ID 建立 canonical 交易事件。
