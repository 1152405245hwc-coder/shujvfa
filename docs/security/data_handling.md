# V0.1 数据处理说明

## 当前措施

- 默认不持久化上传案件。
- 不保存起诉书、陈述或CSV原文件。
- SQLite及报告中的账号只保留末四位。
- `.env`、`data/`、数据库文件和输出目录不进入 Git。
- 日志保存输入输出哈希，不保存模型隐性思维过程。
- DeepSeek API Key 仅从环境变量读取。

## 使用限制

V0.1 尚未实现用户认证、磁盘加密、权限隔离、安全删除和密钥管理。因此当前版本只允许
使用虚构材料或已充分去标识化的数据进行开发、审核和演示，不应直接处理真实未脱敏案件。

## 后续安全门槛

任何真实业务试用前，至少需要：威胁建模、访问控制、加密存储、日志脱敏复核、数据删除
策略、模型服务数据条款审查，以及离线或合规部署方案。
