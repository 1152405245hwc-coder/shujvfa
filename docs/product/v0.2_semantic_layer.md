## 1. 本版解决的问题

V0.1 的模型只做一件事：从起诉书提取事实主张。其余判断全部由确定性规则完成。
这带来三类缺口：

1. **提取质量无校验**：主张金额如果不在其引用的原文里，系统照样采信；
2. **漏提无复核**：起诉书里没写、但材料里存在的付款事实，系统不会提示；
3. **表述僵化**：底稿是表格堆叠，回查建议是固定模板，换个案子措辞一模一样。

V0.2 补上这三块，并新增两项工程能力：模型调用溯源、基线漂移检测。

## 2. 新增能力

| 能力 | 说明 | 主要模块 |
| --- | --- | --- |
| 主张金额锚定校验 | 校验主张金额能否在引用原文中逐字找到（含中文数字），找不到的进入复核队列 | `extraction_guard.py`、`chinese_numerals.py` |
| 漏提复核 | 对同一份起诉书做第二次对抗式提取，疑似漏项只作为待人工确认事项 | `claim_audit.py` |

| 冲突矩阵通用化 | 确定性算出第三方账户事实，模型在材料中找相关陈述并标注立场 | `evidence_conflict_service.py` |
| 调查建议个案化 | 模型在确定性事实之上改写回查建议措辞 | `case_report_service.py` |
| 叙述化底稿 | 模型在事实包之上转写全案摘要 | `case_narrative_service.py` |
| 模型调用溯源 | 记录 provider / model / base_url / 提示词 SHA-256 / 调用时点 | `llm/provenance.py` |

```

party_alias_v0.1        主体归并

case_narrative_v0.1     全案摘要转写
```

## 3. 贯穿全部能力的四条约束

这是本版最重要的设计决定。每一项模型能力都必须同时满足：

### 3.1 数字只能来自确定性代码

模型输出的文字中，**每一个数字都必须已存在于确定性计算的结果里**。
违反者整条丢弃，退回模板或表格。

这条封死的是「模型自己算一个数出来当成事实」——
即 `128.6万 − 86万 = 42.6万` 这类推导。**推导不是事实**。

### 3.2 引文必须逐字命中

模型给出的任何依据，都必须能在材料原文中逐字找到。命中不了整条丢弃并记录。

### 3.3 模型只能补充，不能覆盖

- 主体归并：模型只能**提出候选**，未经人工确认不得生效；
- 冲突优先级：模型只能**提升**、不能降低确定性算出的优先级；
- 回查事项：模型只能改措辞，不能增删事项、不能改类型与优先级。

### 3.4 降级必须可见

任何模型环节失败（密钥缺失、调用失败、输出被拒），都必须
①退回确定性结果；②在界面与报告中显式记录原因。**不允许静默降级**。

## 4. 真实 API 实测中暴露并修正的问题

| 发现 | 修正 |
| --- | --- |
| 模型把「证言直接支持」与「模型自述属于推断」两个别名放进同一组、统一标为 high，审阅人确认整组时弱依据被带过 | 确认粒度下沉到**单个别名**，每个别名各自持有依据与置信度、各自确认 |
| 模型把流转账户的复核优先级从「高」下调为「中」 | 改为**只升不降**：优先级是确定性排序信号，模型不得掩埋结构性风险 |
| 模型把 `DISPUTED`、`THIRD_PARTY_RECIPIENT` 等原始枚举写进司法文书 | 状态码与理由码统一经中文标签表转换；事实包附 `code_labels` 供模型取用 |
| 同一留出集连跑两次，输入 token 完全一致、输出 token 差 2 | 判定逻辑区分方向：**仅输入漂移**才是模型/分词器变更信号；仅输出漂移属生成非确定性 |

## 5. 浏览器交互验收与集成层修复

本版全部能力均经过真实浏览器验收。验收过程中发现 **4 个单元测试无法捕获的集成缺陷**：

1. **模型增强在 UI 中从未生效**：缓存函数收到的是 SHA-256 哈希而非序列化 JSON，
   `json.loads` 解析十六进制串失败，三个缓存函数全部异常，路径被静默中断；
2. **非连字符案件编号导致页面崩溃**：`GOLD_CASE_001` 无连字符，
   编号推导函数解包失败；
3. **增强失败无提示**：失败与「本来就没内容」在界面上无法区分；
4. **增强结果页面不可见**：回查清单条目在增强之前就已渲染，
   全案摘要只进导出文件、页面根本不渲染。

4 项均已修复并补测试。**教训：参数类型、渲染顺序、页面可见性这三类问题，
单元测试在结构上就无法覆盖。**

Gold Cases 与内部留出集均为项目内部构造的公开虚构材料。
两者的通过率只说明公开回归集上的表现，**不得表述为独立盲测准确率**，
也不构成任何法律结论。
