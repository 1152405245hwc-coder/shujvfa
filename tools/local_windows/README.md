# 本地 Windows 调试脚本（非比赛运行入口）

本目录脚本**仅用于开发者在个人 Windows 机器上本地调试**，不属于比赛提交的运行入口。
比赛评审请使用仓库根目录的 `Dockerfile`（单容器），见 `README_SUBMISSION.md`。

| 文件 | 用途 |
| --- | --- |
| `启动资金链证审.bat` | 本地一键启动：首次运行自动创建 `.venv` 并安装依赖，之后直接启动 |
| `双击启动.bat` / `start.bat` | 旧入口，假定 `.venv` 已就绪，直接调用 `start_ui.ps1` |
| `start_ui.ps1` | 启动 Streamlit（健康检查后打开宿主机浏览器） |
| `启动系统(静默后台).vbs` | 无窗口后台启动 |
| `创建桌面快捷方式.bat` | 在桌面生成指向 `双击启动.bat` 的快捷方式 |
| `关闭后台服务.bat` | 停止本地 Streamlit 进程并释放 8501 端口 |

注意：这些脚本会主动打开宿主机浏览器，不符合容器化评审环境，请勿在比赛镜像中使用。
